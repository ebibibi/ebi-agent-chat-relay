# Ebi Agent Chat Relay 5.1.0 — Ebi AI Console and Ebi Workspace

Ebi AI Console now connects conversations to the projects and tasks in **Ebi Workspace**.
The Console remains the optional web GUI of the open-source Ebi Agent Chat Relay. Ebi Workspace
is a separate, paid plugin; the Console works without it.

## Start from the project, not an empty conversation

When Workspace is explicitly configured in the environment running the Console, it appears
in the navigation and new-work selector. Browse contexts and projects, read their overview,
and add, edit or complete the tasks stored in Markdown. **Run with AI** starts work with that
project's context. Associated conversations appear alongside the project.

The Console reads and updates the existing Markdown files; it does not create a second task
store. Revision checks reject stale edits. See [Workspace setup and behavior](../console.md).

## Keep delegated work together

Parent and child threads share a visible group border, role labels, connecting lines and child
counts. Filtered or folded groups report how many children are visible. Clicking either row
opens the parent conversation. You can inspect a child and explicitly enable a direct reply.
Completing a parent completes descendants first; failures leave the affected ancestors open.

Choose the manager and child backend, model and effort separately before spawning work. Child
settings can be global or specific to a parent. Available models follow each backend's catalog;
provider access and the existing Pi deployment permission gate still apply.

## Find, share and reuse work

- Search **inside messages**, with matching excerpts and links to resume the relevant thread.
  Coverage depends on available chat history and local transcripts; this is not an unlimited
  archive search.
- Copy a thread link and follow Console links in agent messages.
- Copy a supported text file's complete contents from its attachment row or preview.
- Select a range with Shift, add individual selections with Ctrl or checkboxes, and finish them
  together. Family completion and undo retain the same semantics as single-thread actions.

## Comfortable on desktop and phone

Mobile conversation scrolling is independent of the composer. A compact header and expandable
menu leave more space for reading. Secondary family/activity panels initially collapse on phones.
Japanese/English switches preserve drafts and attachments. Selected threads have a distinct
highlight, background refreshes preserve the visible list position, and Stop acknowledges the
request immediately while the backend processes it.

## Upgrade and compatibility

- Update your existing installation to **v5.1.0** using its normal Git/package workflow.
- Console activation and `CCDB_CONSOLE_*` settings are unchanged. See [the Console guide](../console.md).
- Workspace must be set up on the machine running the Console. Its existing explicit settings
  are used; the Console does not guess an arbitrary Obsidian vault.
- Workspace is optional and sold separately: [Japanese article](https://note.com/ebibibi/n/n300772aeac93)
  / [English article](https://note.com/ebibibi/n/nc327ab1de017).
- No price change is part of this release.
- Automatic completion remains a heuristic. Preparing a response is not confirmed delivery;
  the updated guidance protects that distinction and prohibits automatic completion for threads
  identified as Teams Channel Exporter work in the current prompt.
