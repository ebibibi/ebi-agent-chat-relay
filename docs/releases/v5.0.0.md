# Ebi Agent Chat Relay 5.0.0

Version 5 gives the relay **a GUI of its own: the Ebi AI Console**. Until now every conversation
with an agent happened inside a chat app. The console is a web screen — desktop or phone — where
you see all of them at once, decide what to do now, and act on them.

It is optional. Nothing starts unless `CCDB_CONSOLE_PORT` is set, and Discord and Teams keep
working exactly as before.

## See everything, decide what to do now

- **Every thread on one screen** — chat threads and the console's own conversations, sorted by
  whose move it is (Inbox, Running, To do, Idle), with Recent, a project tree, Snoozed and Done.
- **Focus view** (the default) answers "what do I do now?". A fast model reads each open thread
  with new activity and fills in what nobody set by hand: priority, a deadline the conversation
  names, the next step, whether that step can be done now or must wait, and whether it is bound to
  a place or device. Importance, readiness and place stay separate axes, so "Do this first" is
  always something you can do here and now.
- Triage uses **the cheapest model of the backend you run** (Haiku on Claude, the cheapest catalog
  model on Codex) as a one-shot, tool-less call. A value a person sets always wins.
- **Places** (home, office, work PC) with an "I am at" filter, **due dates** on every row,
  **context usage** per thread, and **pins** for what you are working on now.

## Act without leaving the screen

- Reply with **any file** attached (paste, drop or 📎), and **preview** text, Markdown, HTML
  (sandboxed), CSV and JSON in place.
- Slash commands, skills and CLI built-ins autocomplete in the reply box; **switch backend, model
  and effort** with a picker, per conversation or as the default.
- See and change the **concurrent-session limit**; **pause, resume or stop** a running thread, and
  reorder threads waiting for a slot.
- Finish a thread with one guarded click, with undo.

## Compatibility

- The GUI was called the Relay Console during development. Only the name changed: URLs
  (`/console/…`), `CCDB_CONSOLE_*` settings, the `[console]` extra and the JSON API keep the word
  `console`.
- With the console enabled, automatic triage is on by default. `CCDB_CONSOLE_TRIAGE=0` turns it
  off.
- Database changes are additive and applied in place on start.
- No change to the Discord or Teams frontends, the backends, the REST API or the scheduler.

## What comes next

The GUI will be updated rapidly from here. **Scheduler integration** — managing scheduled tasks
from the console — is next.
